# Streamlit-Data-App
- Built a small Streamlit app that displays data (In this case a water quality dataset). Includes user input, at least one Plotly chart, and descriptive text
- The biscayneBay_waterquality.csv provided in this repository was used for the app.
- User can view the raw data, view charts based on the option they select from the drop box, view a 3D visualization of the bay floor, and view a Plotly map that shows the track of the vehicle used to collect the data
